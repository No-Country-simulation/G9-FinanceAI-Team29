# Ajustes conversacionales y asesoramiento financiero

Se amplió la detección de consultas de orientación para distinguir preguntas informativas de solicitudes de ayuda.

Casos cubiertos:
- Cómo puedo generar/aumentar/mejorar mis ingresos.
- Cómo puedo reducir/bajar mis gastos o gastar menos.
- Cómo puedo salir de deudas o pagarlas.
- Preguntas de seguimiento para simplificar o resumir una respuesta anterior.

El motor de reglas sugiere consultar a un asesor financiero calificado solo cuando existe una señal objetiva: nivel de riesgo alto/crítico, déficit mensual significativo o carga de deuda elevada. El prompt impide agregar esa recomendación cuando el hecho verificado no está presente.
